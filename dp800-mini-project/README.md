# DP-800 Mini Project

Proyecto de ejemplo para practicar SQL Server y funcionalidades de IA relacionadas con la certificación DP-800.

## Estructura

- `docs/`: documentación y arquitectura.
- `database/`: scripts de creación, datos, vistas, procedimientos, seguridad e índices.
- `ai/`: scripts de modelo externo, embeddings, búsqueda vectorial y RAG.
- `tests/`: pruebas SQL.
- `presentation/`: presentación del proyecto.

## Orden sugerido

1. `database/01_create_database.sql`
2. `database/02_create_tables.sql`
3. `database/03_insert_data.sql`
4. Resto de scripts según sus dependencias.

> Los archivos son plantillas iniciales; completa el contenido SQL y añade los documentos y recursos generados para tu proyecto.
